Картка M1. Помилкове повторне відкриття CLOSED -> OPEN
- Версія: гілка exp/m1, мутація ee5e2cc, виправлення c9b4194.
- FR/AC: FR-04 / AC-04-03 (заборона переходу CLOSED -> OPEN).
- Симптом: PATCH /tickets/{id}/status з {"status": "OPEN"} для закритого тікета повертає 200 замість 409, а повторний GET показує статус OPEN.
- Власна гіпотеза: у словнику ALLOWED_TRANSITIONS в app/services.py для стану CLOSED помилково дозволено перехід у OPEN.
- Застосування Skill: tracker-slice v1 (зріз B), режим чату (ручне передавання SKILL.md, slices.md та виводу T10; локальний запуск pytest і ruff студентом).

- Патч (c9b4194): видалено TicketStatus.OPEN.value із множини дозволених переходів для CLOSED в app/services.py.
- Після патча (m1-fixed.log): цільові тести та повний набір T1 (28/28) проходять, ruff — 0 помилок.
